## 特性

- ✅ **无空格分词**：汉字连续书写，依赖元数自动推断边界
- ✅ **元数驱动解析**：动词声明参数数量，自动收集参数
- ✅ **管道操作**：`，` 作为管道符，数据流动
- ✅ **同像性**：代码即数据，支持元编程
- ✅ **自举成功**：用自己编写自己！
- ✅ **模块系统**：`导入`、`导出`、`从` 支持代码组织
- ✅ **标准库**：数学、字符串、文件、时间、网络、JSON等7个模块
- ✅ **错误处理**：源代码片段显示、错误位置高亮、智能建议
- ✅ **包管理器**：安装、卸载、搜索、发布第三方包
- ✅ **VS Code插件**：语法高亮、自动补全、错误诊断


```bash
# 安装包
yan 包 安装 math-utils
```
