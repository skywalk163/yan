**中文为骨，数学为翼。**

一门融合中文表达与数学公式的函数式编程语言。

## 为什么选择言？

### 双轨设计，各司其职

| 中文轨道 | 数学/Python 轨道 |
|---------|-----------------|
| 逻辑流程、控制结构 | 数学计算、算法实现 |
| `若...则...否则...` | `$(x + y * z)` |
| `定 名称 = 值` | `{{numpy.array([1,2,3])}}` |
| 自然、易读 | 精确、强大 |

**中文负责「说什么」，数学负责「怎么算」。**

### 无缝嵌入 Python 生态

```
定 数据={{pd.read_csv("data.csv")}}。
定 均值=$(数据["score"].mean())。
印均值。
```

### 管道流动，一气呵成

```
范围10，只$(x % 2 == 0)，皆$(x * x)，归加0。

→ 求出1-10中偶数的平方和
```

## 语法速览

### 数学表达式 `$(...)`

直接使用中缀数学公式：

```
定x=$(1 + 2 * 3)。          → x = 7
定面积=$(3.14 * r ** 2)。   → 圆面积公式
定结果=$(a if a > b else b)。  → 条件表达式
```

### Python 代码块 `{{...}}`

嵌入任意 Python 代码：

```
定平方={{[x*x for x in range(1, 6)]}}。
定排序={{sorted([3,1,4,1,5,9,2,6])}}。
```

多行代码，最后一行作为返回值：

```
定斐波那契={{
def fib(n):
    a, b = 0, 1
    for _ in range(n):
        a, b = b, a + b
    return a
fib
}}。
```

### 中文核心语法

**定义**

```
定x=10。                        变量定义
定平方=函x乘x x。               函数定义
定距离=函a b $(abs(a - b))。    函数 + 数学表达式
```

**条件**

```
若5大3则"大"否则"小"。
若$(score >= 60)则"及格"否则"不及格"。
```

**管道**

```
10加5，乘2。           → (10+5)*2 = 30
列1 2 3，首。          → 1
列1 2 3，皆乘2。       → [2, 4, 6]
```

**高阶函数**

| 副词 | 作用 | 示例 |
|------|------|------|
| `皆` | 映射 | `列1 2 3，皆$(x * 2)` → [2, 4, 6] |
| `只` | 过滤 | `列1 2 3 4 5，只$(x > 2)` → [3, 4, 5] |
| `归` | 归约 | `列1 2 3，归加0` → 6 |

## 案例：八皇后问题

在 8×8 棋盘上放置 8 个皇后，互不攻击。经典回溯算法，言语言优雅呈现：

```
-- 八皇后问题求解
-- 中文定义函数名，Python 实现算法

定 安全={{
def safe(queens, row):
    for i in range(row):
        if queens[i] == queens[row]:
            return False
        if abs(queens[i] - queens[row]) == row - i:
            return False
    return True
safe
}}。

定 求解={{
def solve(queens, row, n):
    if row == n:
        return [queens[:]]
    solutions = []
    for col in range(n):
        queens.append(col)
        if safe(queens, row):
            solutions += solve(queens, row + 1, n)
        queens.pop()
    return solutions
solve
}}。

印求解列，0，8。
```

**运行结果：找到全部 92 个解！**

```
[[0, 4, 7, 5, 2, 6, 1, 3], 
 [0, 5, 7, 2, 6, 3, 1, 4],
 ...
 [7, 3, 0, 2, 5, 1, 6, 4]]
```

### 为什么这样写？

| 部分 | 语言 | 原因 |
|------|------|------|
| `定安全`、`定求解` | 中文 | 函数名语义清晰 |
| 回溯算法实现 | Python | 算法逻辑复杂，Python 表达力强 |
| `印求解列，0，8` | 中文 | 调用语句一目了然 |

**各取所长，浑然天成。**

## 设计哲学

### 简洁

「言简意赅」—— 代码如文言，一气呵成，无冗余符号。

### 实用

「言之有物」—— 双轨设计，中文表达逻辑，数学精确计算，Python 复用生态。

### 自然

「言必信」—— 代码即文档，所见即所得，命名即注释。
