# 言语言 (Yán)

> **文言为表，函数为里

言语言是一种文言风格的函数式编程语言。

## 🏆 里程碑

**2026-05-16 - 自举成功！** ✅

言语言已成功实现自举！

## 特性

- ✅ **无空格分词：汉字连续书写，依赖元数自动推断边界
- ✅ **元数驱动解析：动词声明参数数量，自动收集参数
- ✅ **管道操作：`，` 作为管道符，数据流动
- ✅ **同像性：代码即数据，支持元编程
- ✅ **自举成功：用自己编写自己！
