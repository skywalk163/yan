# 关键字双字化改造设计

## 概述

将所有单字关键字改为双字关键字，消除分词歧义，简化词法分析器逻辑。

## 原则

- **只支持新语法**：全部改为2字关键字，现有代码需要迁移
- **直译式命名**：使用最直观、最符合中文表达习惯的词汇

## 关键字替换方案

### 控制流关键字

| 原关键字 | 新关键字 | 说明 |
|---------|---------|------|
| `定` | `定义` | 变量/函数定义 |
| `函` | `函数` | 函数声明 |
| `若` | `如果` | 条件判断开始 |
| `则` | `那么` | 条件分支 |
| `否则` | `否则` | （保持不变） |
| `遍历` | `遍历` | （保持不变） |
| `当` | `当时` | 当...时 |
| `返回` | `返回` | （保持不变） |

## 实施步骤

1. **修改 lexer.py**
   - 更新 `_SINGLE_CHAR_KEYWORDS` 集合，移除已双字化的关键字
   - 更新 `_MULTI_CHAR_KEYWORDS` 集合，添加新的双字关键字
   - 清理 `known_multi_char_words` 相关逻辑（可能不再需要）

2. **修改 parser.py**
   - 更新所有关键字检查的位置
   - 包括 `statement_start_keywords`、`block_start_keywords` 等

3. **更新示例文件**
   - examples/ 目录下的所有 .yan 文件

4. **运行测试**
   - 确保所有 76 个测试通过

## 文件清单

### 需要修改的文件

- `yan/lexer.py` - 关键字定义
- `yan/parser.py` - 关键字检查
- `examples/*.yan` - 所有示例文件

## 预期效果

- 分词逻辑大幅简化
- 消除单字关键字与用户变量名的歧义
- 代码可读性提升
