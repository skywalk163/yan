# 语法优化 v2：移除代码块结束句号

## 概述

优化言语言语法，减少视觉噪音，提升可读性。

## 语法变更规则

### 移除代码块结束句号

| 场景 | 改进前 | 改进后 |
|------|--------|--------|
| **if 语句块** | `当 x: 语句。` `。` | `当 x: 语句` |
| **否则分支** | `否则：` `语句。` `。` | `否则: 语句` |
| **函数定义** | `定 f = 函: 语句。` `。` | `定 f = 函: 语句` |
| **for 循环** | `当 i 小于 n:` `语句。` `。` | `当 i 小于 n: 语句` |

### 改进对比示例

```yan
-- 改进前
定 读配置 = 函 文件路径：
  当 不 存在 文件路径：
    返回 典。
  。
  定 扩展名 = 扩展名 文件路径。
  当 扩展名 等于 ".json"：
    返回 读JSON配置 文件路径。
  。
  返回 读JSON配置 文件路径。
.

-- 改进后
定 读配置 = 函 文件路径：
  当 不 存在 文件路径：
    返回 典
  定 扩展名 = 扩展名 文件路径
  当 扩展名 等于 ".json"：
    返回 读JSON配置 文件路径
  返回 读JSON配置 文件路径
```

## 实现要点

1. **解析器修改**
   - 识别代码块结束（缩进减少）时，不再期待句号
   - 语句仍以换行或显式句号结束

2. **向后兼容**
   - 提供迁移工具自动转换现有代码
   - 新语法 v2 与旧语法 v1 区分

3. **错误提示**
   - 当检测到多余句号时，友好提示
