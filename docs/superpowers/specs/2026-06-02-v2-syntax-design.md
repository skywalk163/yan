## 1. 设计目标

基于 langbyracket 和 yanlv 项目经验，创建言语言 v2 语法层：

| 目标 | 说明 |
|------|------|
| 双字关键字 | 使用双字关键字消除歧义 |
| 缩进分块 | 通过缩进判断代码块结束 |
| 无空格语法 | 支持中文无空格输入 |
| 百家姓变量 | 变量名必须以百家姓开头 |
| 向后兼容 | v1 语法继续支持 |

## 3. 双字关键字系统

### 3.1 核心关键字列表

| 语法类别 | 关键字 | 语义说明 |
|---------|--------|---------|
| 声明 | 定义、常量、赋值 | 变量声明与赋值 |
| 函数 | 函数、参数、返回 | 函数定义与调用 |
| 条件 | 如果、那么、否则、否则当 | 条件分支 |
| 循环 | 对于、遍历、当满足、跳出、继续 | 循环控制 |
| 运算 | 相加、相减、相乘、相除、取余、乘方 | 算术运算 |
| 比较 | 等于、不等、大于、小于、大于等于、小于等于 | 比较运算 |
| 逻辑 | 并且、或者、非也 | 逻辑运算 |
| 异常 | 尝试、捕获、抛出、最终 | 异常处理 |
| 模块 | 导入、导出、开放 | 模块管理 |

### 3.2 分词规则

1. **预分割**：按字符类型自动分界
2. **关键字匹配**：按「先长后短」优先匹配双字关键字
3. **位置修正**：核心关键字仅在固定语法位置生效

## 4. 缩进分块机制

### 4.1 语法示例

```yan
-- @syntax v2

定义 阶乘 = 函数 参数 n:
    如果 n 小于等于 1 那么
        返回 1
    否则
        返回 n 相乘 阶乘 (n 相减 1)

定义 主程序 = 函数:
    定义 结果 = 阶乘 5
    打印 结果
```

### 4.2 设计要点

- 使用冒号 `:` 标记代码块开始
- 通过缩进级别判断代码块结束
- 支持任意缩进风格（空格/制表符）
- 自动检测缩进宽度

## 5. 百家姓变量名识别

### 5.1 识别规则

1. 变量名首字符必须是百家姓
2. 后续字符可以是中文、英文、数字、下划线
3. 双字关键字不能作为变量名

## 7. 版本识别机制

### 7.1 文件头标记

```yan
-- @syntax v2

定义 变量 = 10
```

### 7.2 入口逻辑

```python
def parse_file(filepath):
    with open(filepath, 'r', encoding='utf-8') as f:
        first_line = f.readline().strip()
    
    if first_line.startswith('-- @syntax v2'):
        from v2.parser import ParserV2
        return ParserV2().parse(filepath)
    else:
        from parser import Parser
        return Parser().parse(filepath)
```
