## 2. 函数式编程进阶

### 2.1 高阶函数

```yan
定 应用两次 = 函 f x. f (f x)。
定 平方 = 函 x. 乘 x x。
印 应用两次 平方 3。  -- 输出: 81
```

### 2.2 函数组合

```yan
定 组合 = 函 f g x. f (g x)。
定 加一 = 函 x. 加 x 1。
定 乘二 = 函 x. 乘 x 2。
定 加一乘二 = 组合 乘二 加一。
印 加一乘二 5。  -- 输出: 12
```

### 2.3 柯里化

```yan
定 加法器 = 函 a. 函 b. 加 a b。
定 加五 = 加法器 5。
印 加五 3。  -- 输出: 8
```

### 2.4 记忆化

```yan
定 memoize = 函 f.
  定 缓存 = 典。
  函 x.
    当 存在键 缓存 x:
      返回 值 缓存 x。
    。
    定 结果 = f x。
    设 缓存 x 结果。
    返回 结果。
  。
.

定 斐波那契 = memoize (函 n.
  当 小于等于 n 1:
    返回 1。
  。
  返回 加 (斐波那契 减 n 1) (斐波那契 减 n 2)。
)。
```

### 3.1 异步执行

```yan

等待 任务1, 任务2。
印 "所有任务完成"。
```

### 3.2 并行处理

```yan
定 处理列表 = 函 数据 处理器.
  定 任务 = 映射 (函 x. 异步 (函. 处理器 x)) 数据.
  返回 等待所有 任务.
.

定 结果 = 处理列表 列 1 2 3 4 (函 x. 乘 x 2)。
印 结果。  -- 输出: [2, 4, 6, 8]
```

## 5. 性能优化技巧

### 5.1 缓存计算结果

```yan
定 缓存 = 典。
定 计算 = 函 x.
  当 存在键 缓存 x:
    返回 值 缓存 x。
  。
  定 结果 = 复杂计算 x。
  设 缓存 x 结果。
  返回 结果。
.
```

### 5.2 惰性求值

```yan
定 生成器 = 函 起始.
  定 当前 = 起始。
  返回 函.
    定 结果 = 当前。
    设 当前 加 当前 1。
    返回 结果。
  。
.

定 序列 = 生成器 1。
印 序列。  -- 输出: 1
印 序列。  -- 输出: 2
```

### 5.3 避免重复计算

```yan
定 预计算 = 函 f 列表.
  定 结果 = 典。
  定 i = 0。
  当 i 小于 长 列表:
    设 结果 (取 列表 i) (f (取 列表 i))。
    定 i = 加 i 1。
  。
  返回 结果。
.
```

## 附录：常用设计模式

### 单例模式

```yan
定 单例 = 函 创建器.
  定 实例 = 空。
  返回 函.
    当 实例 等于 空:
      设 实例 创建器。
    。
    返回 实例。
  。
.
```

### 工厂模式

```yan
定 创建形状 = 函 类型.
  当 等于 类型 "圆形":
    返回 典 "类型" "圆形" "面积" (函 r. 乘 圆周率 乘 r r)。
  。
  当 等于 类型 "矩形":
    返回 典 "类型" "矩形" "面积" (函 w h. 乘 w h)。
  。
.
```

### 观察者模式

```yan
定 创建主题 = 函.
  定 观察者 = 列。
  定 订阅 = 函 f. 添 观察者 f。
  定 通知 = 函 数据.
    定 i = 0。
    当 i 小于 长 观察者:
      (取 观察者 i) 数据。
      定 i = 加 i 1。
    。
  。
  返回 典 "订阅" 订阅 "通知" 通知。
.
```
