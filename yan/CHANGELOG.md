## v0.3.0 (2026-05-18)

### 新增功能

#### 标准库扩展
- **加密模块** (`lib/加密.yan`):
  - 支持 MD5、SHA1、SHA256、SHA512 哈希函数
  - Base64 编码/解码（标准和 URL 安全版本）
  - HMAC 签名（支持多种算法）
  - UUID 生成（版本 1 和版本 4）
  - CRC32 校验和安全字符串比较

- **数据库模块** (`lib/数据库.yan`):
  - SQLite 数据库连接管理
  - 表操作：创建、查询、插入、更新、删除
  - 事务管理：开始、提交、回滚
  - 索引管理和批量执行
  - 数据库备份功能

#### 测试框架完善
- **断言函数库** (`yan_assertions.py`):
  - 新增正则匹配断言（串匹配、串搜索）
  - 新增深度比较断言（YanAssertion.diff）
  - 新增列表无序相等断言
  - 新增异常匹配断言和组合断言

- **测试发现机制** (`yan_test_discover.py`):
  - 目录递归搜索测试文件
  - 标签过滤（包含/排除标签）
  - 测试优先级系统（CRITICAL/HIGH/NORMAL/LOW）
  - 测试跳过机制和模式匹配过滤

- **代码覆盖率统计** (`yan_coverage.py`):
  - 行覆盖率统计
  - 分支覆盖率统计
  - 函数覆盖率统计
  - 多种输出格式（text/JSON/HTML）

#### 错误处理增强
- **错误分类系统** (`error_types.py`):
  - 统一的错误类型枚举（E1xx-E6xx）
  - 错误严重级别（ERROR/WARNING/INFO/HINT）
  - 自定义异常类

- **上下文感知错误** (`error_context.py`):
  - 错误上下文提取（代码片段、行号、列号）
  - 变量状态捕获
  - 格式化错误显示

- **智能建议引擎** (`error_suggestions_v2.py`):
  - 拼写纠错（基于相似度匹配）
  - 模式匹配建议
  - 上下文感知建议

#### 性能优化
- **优化词法分析器** (`lexer_optimized.py`):
  - Token 缓存机制
  - O(1) 关键字查找
  - 字符缓冲区优化

- **惰性列表优化** (`list_optimized.py`):
  - 延迟计算支持
  - 流式处理
  - 内存高效的数据处理

### Bug 修复

- 修复词法分析器对英文点号和括号的支持
- 修复解析器成员访问语法问题
- 修复字典创建运行时错误
