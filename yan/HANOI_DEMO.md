# 汉诺塔问题 - 纯言语言实现

## 演示代码

```yan
-- 汉诺塔问题演示（纯言语言实现）

-- 定义汉诺塔函数（简化版）
定汉诺塔=函盘子数 源柱 辅助柱 目标柱：
  若盘子数等1则印源柱 " -> " 目标柱。
  否则印"需要移动" 盘子数 "个盘子"。
。

印"=== 汉诺塔问题演示 ==="。
印""。

印"1个盘子："。
汉诺塔1 "A" "B" "C"。

印""。
印"2个盘子："。
汉诺塔2 "A" "B" "C"。

印""。
印"3个盘子："。
汉诺塔3 "A" "B" "C"。

印""。
印"=== 演示完成 ==="。
```

## 使用的言语言特性

1. **中文变量名**：`盘子数`、`源柱`、`辅助柱`、`目标柱`
2. **中文数字**：`一`、`二`、`三`
3. **中文比较操作符**：`等`（等于）
4. **中文条件语句**：`若...则...否则...`
5. **中文函数定义**：`定汉诺塔=函...`
6. **中文打印**：`印...`

## 核心功能

### 1. 变量定义的多种方式

```yan
张三=10。           -- 省略"定"，使用"="
张三等于10。        -- 使用"等于"赋值
张三等于十。        -- 使用中文数字
定张三=10。         -- 传统方式
```

### 2. 中文数字支持

```yan
一等于一。          -- True
十加二十。          -- 30
一百二十三。        -- 123
```

### 3. 中文和数学混用

```yan
张三等于10。        -- 阿拉伯数字
李四等于二十。      -- 中文数字
张三加李四。        -- 30
```
