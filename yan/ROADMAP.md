# 言语言项目架构改进路线图

## 📖 文档说明

本文档描述了言语言项目的架构改进计划，旨在系统性地提升项目质量、可维护性和功能完整性。

---

## 一、项目现状评估

### 1.1 现有架构概览

| 模块 | 状态 | 说明 |
|------|------|------|
| **词法分析器** | ✅ 稳定 | `lexer.py` |
| **语法分析器** | ✅ 稳定 | `parser.py` |
| **代码生成器** | ⚠️ 需重构 | `codegen.py`（混合了优化器逻辑） |
| **运行时系统** | ✅ 基础完备 | `runtime.py` |
| **模块系统** | ⚠️ 需增强 | `module_system.py` |
| **优化器** | 🚧 基础版 | `codegen.py` 中的 `ASTOptimizer` |
| **调试器** | ⚠️ 基础版 | `yan_debugger.py` |
| **包管理器** | 🚧 基础版 | `yan_package_manager.py` |

### 1.2 架构问题识别

| 问题类型 | 具体问题 | 影响 |
|---------|---------|------|
| **职责混杂** | 优化器逻辑嵌入代码生成器 | 难以扩展和测试 |
| **配置分散** | 配置项分散在多个文件 | 维护困难 |
| **测试不足** | 核心功能测试覆盖不足 | 回归风险高 |
| **文档缺失** | 架构文档、API 文档不完善 | 新开发者上手困难 |
| **错误处理** | 错误恢复能力有限 | 用户体验不佳 |

---

## 二、改进目标与优先级

### 2.1 总体目标

1. **架构清晰度**：建立清晰的分层架构和模块边界
2. **可扩展性**：支持灵活的扩展和定制
3. **开发体验**：提供完善的开发工具和文档
4. **生产就绪**：达到生产环境可用的质量标准

### 2.2 优先级矩阵

| 优先级 | 改进领域 | 时间框 | 关键成果 |
|--------|---------|--------|---------|
| **P0** | 优化器架构重构 | 2-3周 | 独立优化器模块，支持插件化 |
| **P0** | 测试体系完善 | 2-3周 | 测试覆盖率提升至 80%+ |
| **P1** | 模块系统增强 | 3-4周 | 包管理、循环依赖、热更新 |
| **P1** | 错误处理增强 | 2周 | 错误恢复、更好的错误提示 |
| **P2** | 调试器完善 | 3-4周 | 完整调试协议支持 |
| **P2** | 文档完善 | 持续 | API文档、架构文档、教程 |
| **P3** | 多目标代码生成 | 4-6周 | 支持 JavaScript/WebAssembly |
| **P3** | 安全性增强 | 持续 | 沙箱执行、输入验证 |

## 三、详细改进计划

### 阶段一：优化器架构重构（P0）

**目标**：将优化器逻辑从代码生成器中分离，建立独立的优化器框架

#### 3.1.1 重构优化器模块

**任务**：
- [ ] 创建 `optimizer/` 目录
- [ ] 将 `ASTOptimizer` 移至 `optimizer/optimizer.py`
- [ ] 将各优化实现移至 `optimizer/optimizations/` 子目录
- [ ] 实现优化策略模式接口
- [ ] 添加优化依赖分析

**预期产出**：
```
optimizer/
├── __init__.py
├── optimizer.py      # 主优化器类
├── optimizations/
│   ├── __init__.py
│   ├── constant_folding.py
│   ├── dead_code_elimination.py
│   ├── expression_simplification.py
│   └── tail_recursion_optimization.py
└── strategy.py       # 策略模式接口
```

#### 3.1.2 实现优化级别体系

**任务**：
- [ ] 定义优化级别枚举（`O0`, `O1`, `O2`, `Os`）
- [ ] 实现优化级别与优化策略的映射
- [ ] 添加优化级别命令行参数支持

**优化级别定义**：
| 级别 | 名称 | 优化内容 |
|------|------|---------|
| O0 | 无优化 | 不执行任何优化 |
| O1 | 基础优化 | 常量折叠、死代码消除 |
| O2 | 完全优化 | 所有优化 + 尾递归优化 |
| Os | 空间优化 | 优化代码大小 |

#### 3.1.3 添加优化统计和诊断

**任务**：
- [ ] 实现优化统计收集
- [ ] 添加优化诊断输出
- [ ] 支持优化效果分析
