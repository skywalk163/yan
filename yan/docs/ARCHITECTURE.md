# 言语言编译器架构文档

## 概述

言语言（Yan）是一门中文编程语言，其编译器采用模块化架构设计，包含词法分析、语法解析、语义分析、代码生成等核心阶段。本文档详细介绍言语言编译器的整体架构和各个模块的设计。

## 整体架构

言语言编译器采用经典的编译器架构，包含以下几个核心阶段：

```
源代码 → 词法分析 → 语法分析 → 语义分析 → 优化 → 代码生成 → 目标代码
```

## 核心模块

### 1. 词法分析器 (Lexer)

**模块位置：** `yan/lexer.py`

词法分析器负责将源代码文本转换为 Token 序列。言语言的词法分析器支持中文关键字和标识符。

**核心类：**

| 类名 | 说明 |
|------|------|
| `Lexer` | 主词法分析器类 |
| `Token` | Token 数据结构 |

**Token 类型：**

| 类型 | 说明 | 示例 |
|------|------|------|
| `NUMBER` | 数字 | `123`, `3.14` |
| `STRING` | 字符串 | `"你好"`, `'hello'` |
| `IDENTIFIER` | 标识符 | `函数`, `变量` |
| `KEYWORD` | 关键字 | `如果`, `则`, `循环` |
| `OPERATOR` | 运算符 | `+`, `-`, `*`, `/` |
| `PUNCTUATION` | 标点 | `（`, `）`, `，`, `。` |

**关键方法：**

```python
def tokenize(self, source: str) -> List[Token]
def next_token(self) -> Token
def peek(self) -> Token
```

### 2. 语法解析器 (Parser)

**模块位置：** `yan/parser.py`

语法解析器负责将 Token 序列转换为抽象语法树（AST）。言语言采用递归下降解析器。

**核心类：**

| 类名 | 说明 |
|------|------|
| `Parser` | 主解析器类 |
| `ASTNode` | AST 节点基类 |

**AST 节点类型：**

| 节点类型 | 说明 |
|----------|------|
| `ProgramNode` | 程序根节点 |
| `FunctionNode` | 函数定义节点 |
| `CallNode` | 函数调用节点 |
| `IfNode` | 条件语句节点 |
| `LoopNode` | 循环语句节点 |
| `AssignNode` | 赋值语句节点 |
| `BinaryOpNode` | 二元运算节点 |
| `UnaryOpNode` | 一元运算节点 |
| `LiteralNode` | 字面量节点 |
| `IdentifierNode` | 标识符节点 |

### 3. 抽象语法树 (AST Nodes)

**模块位置：** `yan/nodes.py`

定义所有 AST 节点类型。

**节点类层次：**

```
ASTNode (基类)
├── ExpressionNode
│   ├── LiteralNode
│   ├── IdentifierNode
│   ├── BinaryOpNode
│   ├── UnaryOpNode
│   └── CallNode
└── StatementNode
    ├── AssignNode
    ├── IfNode
    ├── LoopNode
    ├── ReturnNode
    ├── FunctionNode
    └── ProgramNode
```

### 4. 代码生成器 (Codegen)

**模块位置：** `yan/codegen.py`

代码生成器负责将 AST 转换为目标代码（Python）。

**核心方法：**

```python
def generate(self, node: ASTNode) -> str
def visit_program(self, node: ProgramNode) -> str
def visit_function(self, node: FunctionNode) -> str
def visit_if(self, node: IfNode) -> str
def visit_loop(self, node: LoopNode) -> str
```

### 5. 优化器 (Optimizer)

**模块位置：** `yan/optimizer/`

优化器采用策略模式，支持多种优化策略。

**模块结构：**

```
optimizer/
├── optimizer.py        # 主优化器
├── strategy.py        # 优化策略接口
└── optimizations/
    ├── constant_folding.py        # 常量折叠
    ├── dead_code_elimination.py    # 死代码消除
    ├── expression_simplification.py # 表达式简化
    └── tail_recursion_optimization.py # 尾递归优化
```

**优化级别：**

| 级别 | 说明 |
|------|------|
| `O0` | 无优化 |
| `O1` | 基础优化（常量折叠、死代码消除） |
| `O2` | 高级优化（+表达式简化、尾递归优化） |
| `Os` | 空间优化（偏向减小代码体积） |

## 错误处理

### 1. 错误恢复 (Error Recovery)

**模块位置：** `yan/error_recovery.py`

编译器错误恢复机制。

**恢复策略：**

| 策略 | 优先级 | 说明 |
|------|--------|------|
| `InsertMissingTokenStrategy` | 30 | 插入缺失关键字 |
| `ReplaceInvalidTokenStrategy` | 40 | 替换无效令牌 |
| `SkipStatementStrategy` | 50 | 跳过错误语句 |
| `ContinueAfterErrorStrategy` | 60 | 运行时错误继续 |

### 2. 智能建议 (Smart Suggestions)

**模块位置：** `yan/smart_error_suggestor.py`

根据错误上下文提供修复建议。

**建议类型：**

| 类型 | 说明 |
|------|------|
| `suggestion` | 一般性建议 |
| `fix` | 代码修复建议 |
| `reference` | 参考信息 |
| `example` | 示例代码 |

### 3. 错误格式化 (Error Formatter)

**模块位置：** `yan/error_formatter.py`

统一错误消息格式化。

**输出格式：**

```text
错误: 语法错误
位置: test.yan:10:5
  │
10 │ 如果 x > 10 则
   │     ^
   │ 缺少 '条件' 关键字

建议: 在 '则' 之前添加条件表达式
```

## 常见问题

### Q: 如何添加新的关键字？

1. 在 `lexer.py` 中添加关键字定义
2. 在 `parser.py` 中添加语法规则
3. 在 `nodes.py` 中添加新节点类型
4. 在 `codegen.py` 中添加代码生成逻辑
5. 添加对应的测试用例

### Q: 如何扩展标准库？

在 `yan/stdlib/` 目录下创建新的 `.yan` 文件，然后在 `__init__.yan` 中导出。

### Q: 如何添加新的优化策略？

1. 在 `optimizer/optimizations/` 下创建新文件
2. 实现 `OptimizationStrategy` 接口
3. 在 `optimizer.py` 中注册新策略
4. 添加测试用例验证优化效果
