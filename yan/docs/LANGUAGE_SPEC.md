# 言语言语法规范 (Language Specification)

**版本：** 0.3.0  
**最后更新：** 2026-05-10

---

## 1. 概述

言语言（Yán）是一种文言风格的函数式编程语言，核心特性包括：
- 无空格分词：汉字连续书写，依赖元数自动推断边界
- 元数驱动解析：动词声明参数数量，自动收集参数
- 管道操作：`，` 作为管道符，数据流动
- 同像性：代码即数据，支持元编程

## 2. 词法规范 (Lexical Specification)

### 2.1 字符集

言语言使用以下字符集：

| 类别 | 字符范围 | 说明 |
|------|----------|------|
| 汉字 | U+4E00 - U+9FFF | CJK 统一汉字 |
| 数字 | 0-9 | 阿拉伯数字 |
| 字母 | a-z, A-Z | 拉丁字母（保留） |
| 结构符 | 。，；：= | 语句结构 |
| 引号 | " ' | 字符串和引用 |
| 特殊 | $ { } ( ) | 数学表达式和代码块 |

### 2.2 Token 类型

```
Token ::= 
    | NUM        // 数字: 1, 2.5, -3
    | STR        // 字符串: "hello"
    | WORD       // 标识符/动词: 加, 乘, 列
    | QUOTE      // 引用: '
    | COMMA      // 管道: ，
    | DOT        // 语句结束: 。
    | SEMI       // 分号: ；
    | COLON      // 块开始: ：
    | EQUALS     // 赋值: =
    | MATH       // 数学表达式: $(...)
    | PYTHON     // Python代码: {{...}}
    | EOF        // 结束
```

### 2.3 词法规则（正则表达式）

```ebnf
NUM     ::= [0-9]+ ('.' [0-9]+)?
STR     ::= '"' [^"]* '"'
WORD    ::= 汉字+ | [a-zA-Z_][a-zA-Z0-9_]*
QUOTE   ::= "'"
COMMA   ::= "，"
DOT     ::= "。"
SEMI    ::= "；"
COLON   ::= "："
EQUALS  ::= "="
MATH    ::= "$(" [^)]* ")"
PYTHON  ::= "{{" [^}]* "}}"
COMMENT ::= ("--" | "注") [^\n]*
```

### 2.4 分词规则

**核心原则：** 代码（动词/标识符）之间无空格，数据之间才需要空格分隔。

**分词算法：**
1. 数字开头 → 切割为 NUM token
2. 汉字开头 → 多字贪心匹配关键字，否则作为 WORD
3. 结构符 → 立即切割
4. 空格 → 仅用于分隔 NUM 与 NUM，其他情况丢弃

**示例：**
```
输入：列1 2 3皆乘2
输出：[WORD:列] [NUM:1] [NUM:2] [NUM:3] [WORD:皆] [WORD:乘] [NUM:2]
```

## 3. 语法规范 (Syntax Specification)

### 3.1 EBNF 语法

```ebnf
(* 程序 *)
Program     ::= Statement* EOF

(* 语句 *)
Statement   ::= Expression ('。' | '；')?
            |   Define
            |   '。' | '；'  (* 空语句 *)

(* 定义 *)
Define      ::= '定' Name '=' Expression

(* 表达式 *)
Expression  ::= Pipeline

(* 管道 *)
Pipeline    ::= Term ('，' Term)*

(* 项 *)
Term        ::= IfExpr
            |   ForeachExpr
            |   WhileExpr
            |   AdverbExpr
            |   CallExpr
            |   Atom

(* 条件表达式 *)
IfExpr      ::= '若' Expression '则' (Block | Expression) 
                ('否则' (Block | Expression))?

(* 遍历循环 *)
ForeachExpr ::= '遍历' Name '于' Expression '：' Block

(* 当循环 *)
WhileExpr   ::= '当' Expression '：' Block

(* 副词表达式 *)
AdverbExpr  ::= Adverb Term

(* 函数调用 *)
CallExpr    ::= Verb Arg*
            |   UserVerb Arg*

(* 原子 *)
Atom        ::= NUM
            |   STR
            |   MATH
            |   PYTHON
            |   QuoteExpr
            |   ListExpr
            |   Name
            |   '真' | '假' | '空'

(* 引用 *)
QuoteExpr   ::= "'" Expression

(* 列表字面量 *)
ListExpr    ::= '列' Atom*

(* 块 *)
Block       ::= '：' Statement* (Statement | '。')

(* 名称 *)
Name        ::= WORD

(* 动词 *)
Verb        ::= BuiltinVerb
UserVerb    ::= WORD  (* 用户定义的函数名 *)

(* 内置动词 *)
BuiltinVerb ::= 
    (* 算术 *)
    '加' | '减' | '乘' | '除' | '模' | '幂' | '绝对' | '负'
    (* 比较 *)
    | '大' | '小' | '等' | '不等'
    (* 逻辑 *)
    | '且' | '或' | '非'
    (* 列表 *)
    | '首' | '余' | '入' | '长' | '添' | '连' | '含' | '空'
    (* 高阶函数 *)
    | '皆' | '只' | '归'
    (* I/O *)
    | '印' | '读' | '写' | '行'
    (* 数据结构 *)
    | '列' | '典' | '序' | '范围'
    (* 标准库 *)
    | 标准库动词...

(* 副词 *)
Adverb      ::= '潜'

(* 参数 *)
Arg         ::= Term

(* 注释 *)
Comment     ::= ('--' | '注') [^\n]*
```

### 3.2 运算符优先级

从高到低：

| 优先级 | 运算符 | 结合性 | 说明 |
|--------|--------|--------|------|
| 1 | `()` `[]` | 左 | 函数调用、列表 |
| 2 | `'` | 右 | 引用 |
| 3 | 中缀动词 | 左 | `加` `减` `乘` `除` 等 |
| 4 | `，` | 左 | 管道 |
| 5 | `若...则...否则` | 右 | 条件 |

### 3.3 元数驱动解析

**核心机制：** 动词声明自己的元数（arity），解析器根据元数自动收集参数。

**元数类型：**
- `arity = 0`：零参数动词（如 `日期`）
- `arity = 1`：单参数动词（如 `首` `余` `长`）
- `arity = 2`：双参数动词（如 `加` `减` `乘` `除`）
- `arity = -1`：可变参数（如 `列` `典`）

**解析规则：**
1. 遇到动词 → 创建 Call 节点，开始收集参数
2. 根据元数决定何时停止收集：
   - `arity > 0`：收集够指定数量的参数后停止
   - `arity = -1`：持续收集直到遇到下一个动词或结构符
3. 遇到新动词 → 当前 Call 完成，开始新的 Call

**示例：**
```
列1 2 3皆乘2

解析过程：
1. 列 (arity=-1) → 开始收集
2. 1, 2, 3 → 收集到 args=[1,2,3]
3. 皆 (副词) → 列完成，皆修饰下一个动词
4. 乘 (arity=2) → 开始收集
5. 2 → 收集到 args=[2]（偏函数）
6. 管道注入 → 乘(列(1,2,3), 2)
```

## 4. 语义规范 (Semantic Specification)

### 4.1 类型系统

言语言是动态类型语言，内置以下类型：

| 类型 | 字面量 | 说明 |
|------|--------|------|
| 数 | `1` `2.5` `-3` | 整数或浮点数 |
| 串 | `"hello"` | 字符串 |
| 表 | `列1 2 3` | 列表 |
| 典 | `典"键"值` | 字典 |
| 函 | `函x x` | 函数 |
| 真 | `真` | 布尔真 |
| 假 | `假` | 布尔假 |
| 空 | `空` | 空值 |

### 4.2 作用域规则

- **全局作用域：** 顶层定义的变量和函数
- **函数作用域：** 函数参数和局部变量
- **块作用域：** 块内定义的变量

**作用域链：** 内部作用域可以访问外部作用域的变量。

### 4.3 求值规则

**严格求值：** 参数在传递给函数前先求值。

**例外：**
- 条件表达式：只求值匹配的分支
- 引用：不立即求值

### 4.4 柯里化规则

当动词参数不足时，返回偏函数：

```
乘2  →  λx. x * 2
加5  →  λx. x + 5
```

**管道注入：** 管道值作为偏函数的第一个参数。

## 6. 双轨制语法 (Dual-Track Syntax)

言语言支持两种嵌入外部代码的方式：

### 6.1 数学表达式

**语法：** `$(表达式)`

**示例：**
```
$(1 + 2 * 3)  →  7
$(x^2 + y^2)  →  x² + y²
```

### 6.2 Python 代码块

**语法：** `{{代码}}`

**示例：**
```
定结果 = {{
import math
math.sqrt(16)
}}  →  4.0
```

## 7. 引用与元编程 (Quote & Metaprogramming)

### 7.1 引用

**语法：** `'表达式`

**语义：** 将表达式转为 AST 数据，不求值。

**示例：**
```
定代码 = '1加2  →  AST: Call(加, [1, 2])
```

### 7.2 求值

**语法：** `行 AST`

**语义：** 将 AST 数据作为代码执行。

**示例：**
```
行'1加2  →  3
```

### 7.3 解引用

**语法：** `,表达式`

**语义：** 在引用内部插入动态内容。

**示例：**
```
定x = 5
定代码 = '乘,x 2  →  AST: Call(乘, [5, 2])
```

## 8. 示例程序

### 8.1 基础运算

```
加1 2。              → 3

```


```
遍历x 于 列1 2 3：
  印x。
。

当x小10：
  印x。
  定x = 加x 1。
。
```

## 9. 实现说明

### 9.1 解析器实现

言语言采用**两遍解析**：

1. **第一遍：** 收集用户定义的函数名
2. **第二遍：** 正常解析，使用收集到的函数名

**原因：** 支持递归函数调用，函数体内可以引用自身。

### 9.2 代码生成

言语言转译到 Python：

```
源码：列1 2 3皆乘2。
Python: _map((lambda _x: _mul(_x, 2)), [1, 2, 3])
```

### 9.3 运行时

言语言运行时提供内置函数：

```python
# 算术
_add(a, b)    # 加
_sub(a, b)    # 减
_mul(a, b)    # 乘
_div(a, b)    # 除

# 高阶函数
_map(f, lst)    # 皆
_filter(f, lst) # 只
_reduce(f, init, lst) # 归
```
