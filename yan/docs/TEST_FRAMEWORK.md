# 言语言测试框架设计

**版本：** 0.3.0  
**最后更新：** 2026-05-10

---

## 1. 设计目标

- **简洁语法**：符合言语言风格
- **清晰断言**：易于理解的断言函数
- **详细报告**：显示通过/失败的测试
- **模块化**：支持测试套件组织

---

## 2. 语法设计

### 2.1 测试定义

**语法：** `测 名称 体`

```
测 "加法测试"
  等 加1 2 3。
。

测 "字符串测试"
  等 连"hello" " world" "hello world"。
。
```

### 2.2 测试套件

**语法：** `套 名称 体`

```
套 "数学运算测试"
  测 "加法"
    等 加1 2 3。
  。
  
  测 "减法"
    等 减5 3 2。
  。
。
```

### 2.3 断言函数

| 函数 | 说明 | 示例 |
|------|------|------|
| 等 | 相等断言 | `等 实际 期望。` |
| 不等 | 不等断言 | `不等 实际 期望。` |
| 大 | 大于断言 | `大 实际 期望。` |
| 小 | 小于断言 | `小 实际 期望。` |
| 真 | 真断言 | `真 条件。` |
| 假 | 假断言 | `假 条件。` |
| 空 | 空断言 | `空 值。` |
| 非 | 非空断言 | `非 值。` |
| 抛 | 异常断言 | `抛 表达式 错误类型。` |

### 2.4 测试前后钩子

```
套 "数据库测试"
  前
    定db = 连接数据库。
  。
  
  后
    关闭数据库db。
  。
  
  测 "查询测试"
    定结果 = 查询db "SELECT * FROM users"。
    非 结果。
  。
。
```

## 3. 运行测试

### 3.1 命令行

```bash
# 运行所有测试
python main.py --test

# 运行指定测试文件
python main.py --test tests/数学测试.yan

# 运行指定测试套件
python main.py --test --suite "数学运算测试"

# 详细输出
python main.py --test --verbose
```

## 5. 示例

### 5.1 基础测试

```
注 基础运算测试

测 "加法测试"
  等 加1 2 3。
  等 加0 0 0。
  等 加-1 1 0。
。

测 "乘法测试"
  等 乘2 3 6。
  等 乘0 5 0。
  等 乘-2 3 -6。
。
```

### 5.2 列表测试

```
测 "列表操作测试"
  定列表 = 列1 2 3。
  
  等 首列表 1。
  等 余列表 列2 3。
  等 长列表 3。
  等 列表皆乘2 列2 4 6。
。
```

### 5.3 函数测试

```
测 "阶乘测试"
  定阶乘 = 函n
    若n等1 则1 否则乘n 阶乘减n 1。
  
  等 阶乘1 1。
  等 阶乘5 120。
  等 阶乘10 3628800。
。
```

### 5.4 异常测试

```
测 "除零测试"
  抛 除1 0 "ZeroDivisionError"。
。

测 "索引越界测试"
  定列表 = 列1 2 3。
  抛 入列表 10 "IndexError"。
。
```
