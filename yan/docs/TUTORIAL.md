## 1. 简介

言语言（Yán）是一种文言风格的函数式编程语言。它的设计理念是：

- **文言为表，函数为里**：外观采用古典文言语法，内部基于纯函数式编程
- **极简主义**：没有括号、没有分号、没有关键字，只有动词与名词的流动
- **管道即自然**：数据如河流，动词如石激起涟漪

## 3. 基础语法

### 3.1 语句

每个语句以句号 `。` 结束：

```
印"hello"。
加1 2。
```

### 3.2 管道

逗号 `，` 表示管道，将前一个结果传给后一个操作：

```
10加5，乘2。
```

等价于 `(10 + 5) * 2 = 30`

### 3.3 注释

以 `注` 或 `--` 开头到行尾：

```
注 这是注释
-- 这也是注释
```

## 10. 高级特性

### 10.1 双轨制语法

**数学表达式：**

```
$(1 + 2 * 3)。  -- 输出: 7
```

**Python 代码块：**

```
定结果 = {{
import math
math.sqrt(16)
}}。
印结果。  -- 输出: 4.0
```

### 10.2 引用与求值

**引用（Quote）：**

```
定代码 = '1加2。  -- 返回 AST，不求值
```

**求值（Eval）：**

```
行'1加2。  -- 输出: 3
```

### 10.3 递归函数

```
定阶乘 = 函n
  若n等1 则1 否则乘n 阶乘减n 1

阶乘5。  -- 输出: 120
```

### 10.4 斐波那契数列

```
定斐波那契 = 函n
  若n小等于1 则n 否则加斐波那契减n 1 斐波那契减n 2。

斐波那契10。  -- 输出: 55
```

## 11. 实战示例

### 11.1 计算列表平均值

```

  定总和 = 列表归加0。
  定数量 = 长列表。
  除总和 数量。

平均值列1 2 3 4 5。  -- 输出: 3.0
```

### 11.2 查找最大值

```
定最大值 = 函列表
  列表归大首列表 最大值余列表。

最大值列3 1 4 1 5 9 2 6。  -- 输出: 9
```

### 11.3 字符串处理

```
引 字符串。

定反转问候 = 函名
  定反转名 = 反转名。
  连"olleH " 反转名。

反转问候"World"。  -- 输出: olleH dlroW
```

### 11.4 JSON 处理

```
引 JSON。

定数据 = 解析'{"name": "张三", "age": 25}'。
印数据。  -- 输出: {'name': '张三', 'age': 25}

定json = 生成数据。
印json。  -- 输出: {"name": "张三", "age": 25}
```

### 11.5 汉诺塔

```
定汉诺塔 = 函n 源 辅 目
  若n等1 则
    印连"移动盘子从" 源 "到" 目。
  否则
    汉诺塔减n 1 源 目 辅。
    印连"移动盘子从" 源 "到" 目。
    汉诺塔减n 1 辅 源 目。
  。
```

## 附录 C：常见问题

### Q: 如何调试代码？

使用 `--debug` 参数：

```bash
python main.py --debug hello.yan
```

### Q: 如何处理错误？

言语言会显示详细的错误信息，包括源代码位置和建议。

### Q: 如何安装第三方模块？

将模块文件放入 `~/.yan/lib/` 或 `~/.yan/packages/` 目录。
