# 言语言 Markdown 格式规范 (YanMD)

## 核心理念

**言语言 = Markdown + 可执行代码块**

- Markdown 是载体，代码是内容
- `#` 标题定义作用域层级
- ` ```lang ` 代码块内嵌任意语言
- 文档即程序，程序即文档

---

## 一、作用域系统

### 1.1 标题定义作用域

```
# 一级作用域

## 二级作用域

### 三级作用域
```

作用域规则：
- 子作用域可以访问父作用域的变量
- 父作用域不能访问子作用域的变量
- 同级作用域之间隔离

### 1.2 作用域示例

```markdown
# 数学工具库

定圆周率=3.14159。

## 几何计算

定面积=函r圆周率乘r乘r。

## 三角函数

定计算正弦=函x正弦x。
```

执行顺序：
1. 进入 `# 数学工具库`，定义 `圆周率`
2. 进入 `## 几何计算`，定义 `面积`（可访问 `圆周率`）
3. 进入 `## 三角函数`，定义 `计算正弦`（可访问 `圆周率`，但不能访问 `面积`）

## 二、代码块系统

### 2.1 言语言代码块

````markdown
```yan
定x=10。
印x加5。
```
````

执行言语言代码，输出结果。

### 2.2 Python 代码块

````markdown
```python
import math
print(math.sqrt(16))
```
````

执行 Python 代码，输出结果。

### 2.3 Lisp 代码块

````markdown
```lisp
(defun factorial (n)
  (if (<= n 1) 1 (* n (factorial (- n 1)))))
(print (factorial 5))
```
````

执行 Lisp 代码（需要安装 Lisp 解释器）。

### 2.4 其他语言

支持任意语言，只要系统安装了对应的解释器：
- `javascript` / `js`
- `ruby`
- `go`
- `rust`
- `bash` / `shell`
- ...

### 2.5 只读代码块

不带语言标识的代码块不执行：

````markdown
```
这是普通文本代码块，不执行
```
````

## 四、执行模型

### 4.1 执行顺序

1. 按文档顺序执行
2. 遇到标题：创建新作用域
3. 遇到代码块：执行代码
4. 遇到文本：跳过

### 4.2 作用域栈

```
文档开始
  ↓
# A        → push(A), scope = [A]
  ↓
## B       → push(B), scope = [A, B]
  ↓
## C       → pop(B), push(C), scope = [A, C]
  ↓
# D        → pop(C), pop(A), push(D), scope = [D]
  ↓
文档结束
```

### 4.3 变量查找

```
当前作用域 → 父作用域 → ... → 全局作用域
```

    if n < 2:
        return n
    return fib(n-1) + fib(n-2)

for i in range(1, 11):
    print(fib(i))
```

## 六、与现有格式对比

| 特性 | .yan 格式 | .ymd 格式 |
|------|-----------|-----------|
| 作用域 | 无 | `#` 标题层级 |
| 多语言 | `$()` 和 `{{}}` | ` ```lang ` 代码块 |
| 文档性 | 注释 | Markdown 文本 |
| 可读性 | 代码为主 | 文档为主 |
| 适用场景 | 纯代码 | 文学编程、教程、文档 |
