## 一、概述

言语言（Yán）是一种文言风格的函数式编程语言，采用无空格分词和元数驱动解析。

### 1.1 设计理念

- **文言为表，函数为里**：外观采用古典文言语法，内部基于纯函数式编程范式
- **极简主义**：没有括号、没有分号、没有关键字，只有动词与名词的流动
- **管道即自然**：数据如河流，动词如石激起涟漪

### 1.2 核心特性

- 无空格分词：汉字连续书写，依赖元数自动推断边界
- 元数驱动解析：动词声明参数数量，自动收集参数
- 管道操作：`，` 作为管道符，数据流动
- 同像性：代码即数据，支持元编程

## 二、词法规范

### 2.1 字符集

言语言使用以下字符集：

| 类别 | 字符集 | 说明 |
|------|--------|------|
| 汉字 | U+4E00-U+9FFF | CJK统一汉字，用于标识符和关键字 |
| 数字 | 0-9 | 阿拉伯数字 |
| 标点 | 。，：； | 中文标点符号 |
| 引号 | " ' | 字符串引号 |
| 空白 | 空格、制表符、换行 | 用于分隔数字字面量 |

### 2.2 Token 类型

```
Token ::= 
    | NUM          -- 数字字面量
    | STR          -- 字符串字面量
    | WORD         -- 标识符或关键字
    | DOT          -- 句号 '。'
    | COMMA        -- 逗号 '，'
    | COLON        -- 冒号 '：'
    | SEMI         -- 分号 '；'
    | EQUALS       -- 等号 '='
    | EOF          -- 文件结束
```

### 2.3 数字字面量

```
NUM ::= [0-9]+ ('.' [0-9]+)?

示例：
  42        -- 整数
  3.14      -- 浮点数
  0.5       -- 浮点数
```

### 2.4 字符串字面量

```
STR ::= '"' [^"]* '"'

示例：
  "你好"
  "Hello World"
  "包含\"转义\"的字符串"
```

### 2.5 标识符

```
WORD ::= 汉字+ (汉字 | 数字 | 字母)*

示例：
  数据
  列表1
  函数名
```

### 2.6 关键字

言语言的关键字：

```
关键字 ::= 
    | '定'        -- 定义
    | '函'        -- 函数
    | '若'        -- 如果
    | '则'        -- 那么
    | '否则'      -- 否则
    | '当'        -- 当循环
    | '遍历'      -- 遍历循环
    | '于'        -- 在...中
    | '返回'      -- 返回
    | '真'        -- 布尔真
    | '假'        -- 布尔假
    | '空'        -- 空值
    | '无'        -- 无返回值
    | '导入'      -- 导入模块
    | '导出'      -- 导出符号
    | '结构'      -- 定义结构体
    | '类型'      -- 类型声明
    | '字段'      -- 字段声明
```

### 2.7 注释

```
注释 ::= 
    | '--' [^\n]*           -- 单行注释（双横线）
    | '注' [^\n]*           -- 单行注释（注字开头）

示例：
  -- 这是注释
  注 这也是注释

## 三、语法规范（EBNF）

### 3.1 程序结构

```ebnf
程序     ::= 语句*
语句     ::= 表达式 '。'?
         | 定义语句 '。'?
         | 导入语句 '。'?
         | 导出语句 '。'?

定义语句 ::= '定' 标识符 '=' 表达式
         | '定' 标识符 '=' '函' 参数* '：' 块

导入语句 ::= '导入' 模块名
         | '导入' 标识符+ '于' 模块名

导出语句 ::= '导出' 标识符+

参数     ::= 标识符

块       ::= 语句+ '。'

模块名   ::= 标识符
```

### 3.2 表达式

```ebnf
表达式   ::= 管道链

管道链   ::= 项 ('，' 项)*

项       ::= 动词 参数*
         | 原子
         | 条件表达式
         | 循环表达式

动词     ::= 标识符

参数     ::= 原子
         | 动词 参数*
         | 条件表达式
         | 循环表达式

原子     ::= 数字
         | 字符串
         | 标识符
         | 列表字面量
         | 字典字面量
```

### 3.3 条件表达式

```ebnf
条件表达式 ::= '若' 表达式 '则' 表达式 '否则' 表达式

示例：
  若 大 x 0
    印 "正数"。
  否则
    印 "非正数"。
  。
```

### 3.4 循环表达式

```ebnf
循环表达式 ::= 
    | '当' 表达式 '：' 块
    | '遍历' 标识符 '于' 表达式 '：' 块

示例：
  -- 当循环
  定 i = 0。
  当 小 i 10
    印 i。
    定 i = 加 i 1。
  。

  -- 遍历循环
  遍历 x 于 列 1 2 3
    印 x。
  。
```

### 3.5 列表字面量

```ebnf
列表字面量 ::= '列' (原子 | 表达式)*

示例：
  列 1 2 3
  列 "a" "b" "c"
  列 加 1 2 乘 3 4
```

### 3.6 字典字面量

```ebnf
字典字面量 ::= '典' (键 值)*

键       ::= 原子
值       ::= 原子 | 表达式

示例：
  典 "name" "张三" "age" 25
```

## 四、语义规范

### 4.1 作用域

言语言使用词法作用域：

```yan
定 x = 10。

定 函数 = 函
  定 x = 20。  -- 局部变量
  印 x。      -- 输出 20
。

印 x。        -- 输出 10
```

### 4.2 变量绑定

变量一旦定义，不可重新赋值（函数式编程）：

```yan
定 x = 10。
定 x = 20。  -- 错误：变量已定义
```

### 4.3 函数定义

函数是第一类公民：

```yan
定 平方 = 函 x 乘 x x。
定 应用 = 函 f x f x。

应用 平方 5。  -- 输出 25
```

### 4.4 元数驱动解析

动词声明参数数量，编译器自动收集参数：

```yan
-- 加 的元数是 2
加 1 2。  -- 解析为 加(1, 2)

-- 列 的元数是可变的
列 1 2 3。  -- 解析为 列(1, 2, 3)
```

### 4.5 管道操作

`，` 作为管道符，将左侧结果传递给右侧：

```yan
列 1 2 3，皆 平方，求和。
-- 等价于：求和(皆(平方, 列(1, 2, 3)))
-- 输出：14
```

## 二、求值规则

### 2.1 求值顺序

言语言采用**严格求值**（eager evaluation）：

```yan
定 x = 加 1 2。  -- 先求值 1 和 2，再调用 加
印 x。           -- 输出 3
```

### 2.2 函数求值

函数参数在函数调用前求值：

```yan
定 平方 = 函 x 乘 x x。
定 值 = 平方 加 1 2。  -- 先求值 加 1 2 = 3，再调用 平方 3
印 值。                -- 输出 9
```

### 2.3 条件求值

条件表达式采用**短路求值**：

```yan
-- 只求值满足条件的分支
若 真
  印 "真分支"。
否则
  印 "假分支"。  -- 不求值
。
```

---

## 三、作用域规则

### 3.1 词法作用域

言语言使用**词法作用域**（lexical scoping）：

```yan
定 x = 10。

定 外层 = 函
  印 x。  -- 引用外层的 x = 10
。

定 内层 = 函
  定 x = 20。
  外层。    -- 输出 10，不是 20
。

内层。
```

### 3.2 作用域嵌套

内层作用域可以访问外层作用域：

```yan
定 x = 10。

定 外层 = 函
  定 y = 20。
  
  定 内层 = 函
    印 加 x y。  -- 可以访问 x 和 y
  。
  
  内层。  -- 输出 30
。

外层。
```

### 3.3 变量遮蔽

内层变量可以遮蔽外层变量：

```yan
定 x = 10。

定 函数 = 函
  定 x = 20。  -- 遮蔽外层的 x
  印 x。      -- 输出 20
。

函数。
印 x。        -- 输出 10
```

## 四、类型系统

### 4.1 动态类型

言语言是**动态类型**语言：

```yan
定 x = 10。      -- x 是数
定 x = "hello"。 -- x 是串（允许重新定义）
印 x。           -- 输出 "hello"
```

### 4.2 类型检查

类型在运行时检查：

```yan
加 1 "hello"。  -- 运行时错误：类型不匹配
```

### 4.3 类型转换

言语言不提供自动类型转换：

```yan
加 1 "2"。  -- 错误：不能将串和数相加
```

## 五、函数语义

### 5.1 函数定义

函数定义创建一个函数值：

```yan
定 平方 = 函 x 乘 x x。  -- 平方 是一个函数值
```

### 5.2 函数调用

函数调用时，参数按位置绑定：

```yan
定 加 = 函 x y
  返回 加 x y。  -- 注意：这里的 加 是内置函数
。

加 1 2。  -- x = 1, y = 2
```

### 5.3 闭包

函数可以捕获定义时的环境：

```yan
定 制造加法器 = 函 n
  返回 函 x 加 x n。
。

定 加5 = 制造加法器 5。
加5 10。  -- 输出 15
```

### 5.4 递归

函数可以递归调用自身：

```yan
定 阶乘 = 函 n
  若 等于 n 0
    返回 1。
  否则
    返回 乘 n 阶乘 减 n 1。
  。
。

阶乘 5。  -- 输出 120
```

## 六、列表语义

### 6.1 列表创建

列表是可变的：

```yan
定 列表 = 列 1 2 3。
添 列表 4。  -- 列表变为 [1, 2, 3, 4]
```

### 6.2 列表访问

列表索引从 0 开始：

```yan
定 列表 = 列 10 20 30。
入 列表 0。  -- 输出 10
入 列表 1。  -- 输出 20
入 列表 2。  -- 输出 30
```

### 6.3 列表切片

言语言不支持列表切片，需要使用循环：

```yan

  当 小 i 结束
    定 结果 = 添 结果 入 列表 i。
    定 i = 加 i 1。
  。
  返回 结果。
。
```
