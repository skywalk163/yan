# 言语言入门教程 - 第1章：环境搭建

## 1.1 什么是言语言

言语言（Yan Language）是一门以中文为关键字的函数式编程语言。它的设计目标是：

- **自然语言风格**：使用中文动词作为关键字，代码如读文章
- **函数式编程**：支持高阶函数、lambda、管道操作
- **Python 兼容**：编译为 Python 字节码，可无缝调用 Python 库

## 1.2 安装要求

- Python 3.8+
- Git（可选，用于克隆仓库）

## 1.3 获取源代码

```bash
git clone https://gitcode.net/dumate/newlisp.git
cd newlisp/yan
```

## 1.4 运行第一个程序

创建一个简单的言语言文件 `hello.yan`：

```yan
注 这是一个注释
印 "你好，言语言！"。
```

运行程序：

```bash
python main.py hello.yan
```

输出：
```
你好，言语言！
```

## 1.5 交互模式

运行不带参数的 `main.py` 进入交互模式：

```bash
python main.py
```

交互模式示例：
```
言> 1加2。
  => 3
言> 定 x = 5。
言> x乘3。
  => 15
```

## 1.6 命令行选项

| 选项 | 说明 |
|------|------|
| `--debug` | 显示调试信息（词法分析、语法分析、生成的Python代码） |

示例：
```bash
python main.py hello.yan --debug
```
