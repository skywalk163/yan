# 言语言入门教程 - 第2章：基础语法

## 2.1 注释

言语言使用 `注` 关键字或 `--` 开头表示注释：

```yan
注 这是一行注释
-- 这也是一行注释
```

## 2.2 变量定义

使用 `定义` 关键字定义变量：

```yan
定义 名字 = "张三"。
定义 年龄 = 25。
定义 身高 = 1.75。
定义 已婚 = 为假。
```

## 2.3 数据类型

言语言支持以下数据类型：

### 2.3.1 数字

```yan
定义 整数 = 42。
定义 小数 = 3.14。
定义 负数 = -10。
```

### 2.3.2 字符串

```yan
定义 问候 = "你好"。
定义 多行 = "第一行\n第二行"。
```

### 2.3.3 布尔值

```yan
定义 真的值 = 为真。
定义 假的值 = 为假。
```

### 2.3.4 列表

使用 `列表` 关键字创建列表：

```yan
定义 空列表 = 列表。
定义 数字列表 = 列表 1 2 3 4 5。
定义 混合列表 = 列表 1 "二" 3.0。
```

### 2.3.5 字典

使用 `字典` 关键字创建字典：

```yan
定义 空字典 = 字典。
定义 学生 = 字典 "姓名" "张三" "年龄" 20。
```

## 2.4 基本运算

### 2.4.1 算术运算

```yan
定义 和 = 加 10 5。      => 15
定义 差 = 减 10 3。      => 7
定义 积 = 乘 4 5。       => 20
定义 商 = 除 10 3。      => 3.333...
定义 模 = 模 10 3。      => 1
定义 幂 = 幂 2 10。      => 1024
```

### 2.4.2 比较运算

```yan
定义 大于 = 大于 5 3。     => 为真
定义 小于 = 小于 3 5。     => 为真
定义 相等 = 等于 5 5。     => 为真
定义 不等 = 不等于 5 3。   => 为真
```

### 2.4.3 逻辑运算

```yan
定义 并且 = 且 为真 为假。   => 为假
定义 或者 = 或 为真 为假。   => 为真
定义 否定 = 非 为真。     => 为假
```

## 2.5 函数定义

使用 `定义` 和 `函数` 定义函数：

```yan
定义 平方 = 函数 x 乘 x x。

定义 加法 = 函数 a b 加 a b。

定义 问候 = 函数 姓名
  输出 "你好，"连接姓名连接"！"。
。
```

## 2.6 条件语句

使用 `如果`、`那么`、`否则`：

```yan
定义 年龄 = 18。

如果 大于等于 年龄 18
  那么 输出 "成年人"。
  否则 输出 "未成年人"。
。
```

## 2.7 循环

### 2.7.1 遍历循环

```yan
遍历 数 于 列表 1 2 3
  输出 数。
。
```

### 2.7.2 当循环

```yan
定义 i = 0。
当时 小于 i 10
  输出 i。
  定义 i = 加 i 1。
。
```

## 2.8 小结

本章介绍了言语言的基础语法：
- 注释、变量定义
- 数据类型（数字、字符串、布尔、列表、字典）
- 基本运算（算术、比较、逻辑）
- 函数定义
- 条件语句和循环
