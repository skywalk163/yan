# 言语言入门教程 - 第2章：基础语法

## 2.1 注释

言语言使用 `注` 关键字或 `--` 开头表示注释：

```yan
注 这是一行注释
-- 这也是一行注释
```

## 2.2 变量定义

使用 `定` 关键字定义变量：

```yan
定 名字 = "张三"。
定 年龄 = 25。
定 身高 = 1.75。
定 已婚 = 假。
```

## 2.3 数据类型

言语言支持以下数据类型：

### 2.3.1 数字

```yan
定 整数 = 42。
定 小数 = 3.14。
定 负数 = -10。
```

### 2.3.2 字符串

```yan
定 问候 = "你好"。
定 多行 = "第一行\n第二行"。
```

### 2.3.3 布尔值

```yan
定 真的值 = 真。
定 假的值 = 假。
```

### 2.3.4 列表

使用 `列` 关键字创建列表：

```yan
定 空列表 = 列。
定 数字列表 = 列 1 2 3 4 5。
定 混合列表 = 列 1 "二" 3.0。
```

### 2.3.5 字典

使用 `典` 关键字创建字典：

```yan
定 空字典 = 典。
定 学生 = 典 "姓名" "张三" "年龄" 20。
```

## 2.4 基本运算

### 2.4.1 算术运算

```yan
定 和 = 10加5。      => 15
定 差 = 10减3。      => 7
定 积 = 4乘5。       => 20
定 商 = 10除3。      => 3.333...
定 模 = 10模3。      => 1
定 幂 = 2幂10。      => 1024
```

### 2.4.2 比较运算

```yan
定 大于 = 5大3。     => 真
定 小于 = 3小5。     => 真
定 相等 = 5等5。     => 真
定 不等 = 5不等3。   => 真
```

### 2.4.3 逻辑运算

```yan
定 并且 = 真且假。   => 假
定 或者 = 真或假。   => 真
定 否定 = 非真。     => 假
```

## 2.5 函数定义

使用 `定` 和 `函` 定义函数：

```yan
定 平方 = 函 x 乘x x。

定 加法 = 函 a b 加a b。

定 问候 = 函 姓名
  印 "你好，"连姓名连"！"。
。
```

## 2.6 条件语句

使用 `若`、`则`、`否则`：

```yan
定 年龄 = 18。

若 年龄大等于18
  则 印 "成年人"。
  否则 印 "未成年人"。
。
```

## 2.7 循环

### 2.7.1 遍历循环

```yan
遍历 数 于 列 1 2 3
  印 数。
。
```

### 2.7.2 当循环

```yan
定 i = 0。
当 i小10
  印 i。
  定 i = i加1。
。
```

## 2.8 小结

本章介绍了言语言的基础语法：
- 注释、变量定义
- 数据类型（数字、字符串、布尔、列表、字典）
- 基本运算（算术、比较、逻辑）
- 函数定义
- 条件语句和循环
