# 言语言入门教程 - 第4章：模块系统

## 4.1 模块导入

使用 `引` 关键字导入模块：

```yan
引 数学。
引 JSON。
引 日期。
```

## 4.2 标准库模块

言语言提供了丰富的标准库：

### 4.2.1 JSON模块

```yan
引 JSON。

定 数据 = JSON.解析 "{\"name\": \"张三\", \"age\": 25}"。
印 数据。

定 字符串 = JSON.生成 {"name": "李四", "age": 30}。
印 字符串。
```

### 4.2.2 正则模块

```yan
引 正则。

印 正则.匹配 "^hello" "hello world"。   => 真
印 正则.替换 "\d+" "X" "abc123def"。   => "abcXdef"
```

### 4.2.3 日期模块

```yan
引 日期。

印 日期.当前时间。
印 日期.格式化 日期.当前时间 "%Y-%m-%d %H:%M:%S"。
```

### 4.2.4 网络模块

```yan
引 网络。

定 内容 = 网络.获取 "https://example.com"。
印 内容。
```

### 4.2.5 字符串模块

```yan
引 字符串。

印 字符串.反转 "hello"。   => "olleh"
印 字符串.长度 "你好世界"。   => 4
```

### 4.2.6 数学模块

```yan
引 数学。

印 数学.圆周率。   => 3.14159...
印 数学.正弦 0。   => 0.0
```

## 4.3 创建自定义模块

### 4.3.1 模块文件

创建 `utils.yan`：

```yan
注 工具函数模块

定 平方 = 函 x 乘x x。
定 立方 = 函 x 乘x 乘x x。

出 平方 立方。
```

### 4.3.2 导入自定义模块

```yan
引 utils。

印 utils.平方 5。   => 25
印 utils.立方 3。   => 27
```

## 4.4 Python代码块

使用 `{{...}}` 嵌入 Python 代码：

```yan
定 随机数 = {{import random; random.randint(1, 100)}}。
印 随机数。

定 系统时间 = {{import time; time.time()}}。
印 系统时间。
```

## 4.5 文件操作

### 4.5.1 读取文件

```yan
定 内容 = 读文件 "test.txt"。
印 内容。
```

### 4.5.2 写入文件

```yan
写文件 "output.txt" "你好，言语言！"。
```

### 4.5.3 追加内容

```yan
追加文件 "log.txt" "新的日志行\n"。
```
