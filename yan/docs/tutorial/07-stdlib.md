# 第7章：标准库深度解析

言语言提供了丰富的标准库，涵盖网络、JSON、正则、日期、加密和数据库等功能。

## 7.1 JSON模块

JSON模块提供JSON数据的编码和解码功能。

```yan
引 JSON。

注 基本操作
定 数据 = 典
  "姓名" "张三"
  "年龄" 30
  "爱好" 列"阅读" "编程" "运动"。

注 生成JSON字符串
定 json字符串 = JSON.生成(数据)。
印 json字符串。

注 格式化输出
定 格式化字符串 = JSON.格式化(数据, 2)。
印 格式化字符串。

注 解析JSON
定 解析结果 = JSON.解析(json字符串)。
印 解析结果["姓名"]。

注 从文件读取
定 从文件 = JSON.从文件读取("data.json")。

注 写入文件
JSON.写入文件(数据, "output.json")。
```

### 7.1.1 JSONPath支持

```yan
引 JSON。

定 复杂数据 = 典
  "用户" 列
    典"id" 1 "姓名" "张三" "订单" 列典"id" 100 "金额" 99.9
    典"id" 2 "姓名" "李四" "订单" 列典"id" 101 "金额" 199.9。

注 使用JSONPath提取数据
定 所有订单金额 = JSON.提取路径(复杂数据, "$..金额")。
印 所有订单金额。  # 输出: [99.9, 199.9]

定 用户姓名 = JSON.提取路径(复杂数据, "$.用户[*].姓名")。
印 用户姓名。  # 输出: ["张三", "李四"]
```

## 7.2 网络模块

网络模块提供HTTP请求和文件下载功能。

```yan
引 网络。

注 发送GET请求
定 响应 = 网络.获取("https://api.example.com/data")。
印 响应。

注 发送POST请求
定 表单数据 = 典"username" "user" "password" "pass"。
定 结果 = 网络.发布表单("https://api.example.com/login", 表单数据)。

注 发送JSON数据
定 json数据 = 典"key" "value"。
定 json结果 = 网络.发布JSON("https://api.example.com/api", json数据)。

注 下载文件
网络.下载("https://example.com/file.zip", "file.zip")。

注 带进度的下载
网络.下载进度("https://example.com/large.zip", "large.zip")。

注 URL编码
定 编码 = 网络.编码("测试中文")。
定 解码 = 网络.解码(编码)。
```

## 7.3 正则模块

正则模块提供正则表达式功能。

```yan
引 正则。

注 基本匹配
定 文本 = "Hello World 2024"。

注 匹配开头
定 匹配结果 = 正则.匹配("^Hello", 文本)。
印 匹配结果。

注 搜索
定 搜索结果 = 正则.搜索(r"\d+", 文本)。
印 搜索结果。

注 替换
定 替换结果 = 正则.替换(r"\d+", "XXXX", 文本)。
印 替换结果。  # 输出: Hello World XXXX

注 查找所有匹配
定 所有数字 = 正则.查找全部(r"\d+", "a1b2c3d4")。
印 所有数字。  # 输出: ['1', '2', '3', '4']

注 分割
定 分割结果 = 正则.分割(r"\s+", "Hello World Python")。
印 分割结果。  # 输出: ['Hello', 'World', 'Python']
```

## 7.4 日期模块

日期模块提供日期时间处理功能。

```yan
引 日期。

注 获取当前时间
定 现在 = 日期.当前时间()。
印 现在。

注 格式化日期
定 格式化 = 日期.格式化(现在, "%Y-%m-%d %H:%M:%S")。
印 格式化。

注 解析日期字符串
定 解析 = 日期.解析("2024-01-15", "%Y-%m-%d")。
印 解析。

注 日期计算
定 昨天 = 日期.减天数(现在, 1)。
定 明天 = 日期.加天数(现在, 1)。

注 计算日期差
定 天数差 = 日期.日期差(昨天, 明天)。
印 天数差。  # 输出: 2

注 获取日期各部分
印 日期.年(现在)。
印 日期.月(现在)。
印 日期.日(现在)。
```

## 7.5 加密模块

加密模块提供哈希、编码和UUID生成功能。

```yan
引 加密。

注 哈希函数
定 md5 = 加密.MD5("Hello World")。
定 sha256 = 加密.SHA256("Hello World")。

印 sha256。

注 Base64编码

注 UUID生成

定 uuid4 = 加密.UUID4()。
印 uuid1。
印 uuid4。

注 生成随机字符串
定 随机串 = 加密.生成随机字符串(16)。
印 随机串。
```

## 7.6 数据库模块

数据库模块提供SQLite数据库操作功能。

```yan
引 数据库。

注 连接数据库
定 连接 = 数据库.连接SQLite("example.db")。

注 创建表
数据库.创建表(连接, """
  CREATE TABLE IF NOT EXISTS users (
    id INTEGER PRIMARY KEY AUTOINCREMENT,
    name TEXT,
    age INTEGER
  )
""")。

注 插入数据
定 用户ID = 数据库.插入(连接, "users", 典"name" "张三" "age" 30)。
印 用户ID。

注 查询数据
定 所有用户 = 数据库.查询(连接, "SELECT * FROM users", ())。
印 所有用户。

注 查询单行
定 用户 = 数据库.查询单行(连接, "SELECT * FROM users WHERE id = ?", (1,))。
印 用户。

注 更新数据
数据库.更新(连接, "users", 典"age" 31, "id = ?", (1,))。

注 删除数据
数据库.删除(连接, "users", "id = ?", (1,))。

注 事务处理
数据库.开始事务(连接)。
尝试
  数据库.插入(连接, "users", 典"name" "李四" "age" 25)。
  数据库.插入(连接, "users", 典"name" "王五" "age" 35)。
  数据库.提交事务(连接)。
除
  数据库.回滚事务(连接)。

注 关闭连接
数据库.关闭连接(连接)。
```
