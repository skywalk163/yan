## 8.1 项目一：待办事项管理器

```yan

    CREATE TABLE IF NOT EXISTS todos (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      title TEXT NOT NULL,

      created_at TEXT,
      updated_at TEXT
    )
  """)。

    "title" 标题
    "description" 描述

    "created_at" 时间
    "updated_at" 时间。

  定 时间 = 日期.格式化(日期.当前时间(), "%Y-%m-%d %H:%M:%S")。
  数据库.更新(连接, "todos", 典"completed" 1 "updated_at" 时间, "id = ?", (待办ID,))。

定 获取所有待办 = 函连接
  数据库.查询(连接, "SELECT * FROM todos ORDER BY created_at DESC", ())。

定 获取未完成 = 函连接
  数据库.查询(连接, "SELECT * FROM todos WHERE completed = 0 ORDER BY created_at DESC", ())。

定 删除待办 = 函连接 待办ID
  数据库.删除(连接, "todos", "id = ?", (待办ID,))。

注 使用示例
定 连接 = 初始化数据库()。

添加待办(连接, "学习言语言", "完成进阶教程")。
```

```yan
  匹配。

  定 模式 = r'<title>([^<]+)</title>'。

    则 匹配
    否则 "无标题"。

  定 已访问 = 典。
```

## 8.3 项目三：天气查询应用

```yan
注 天气查询应用

引 网络。
引 JSON。
引 日期。

定 获取天气 = 函城市
  定 API_KEY = "your_api_key"。
  定 URL = "https://api.openweathermap.org/data/2.5/weather"。
  
  定 参数 = 典
    "q" 城市
    "appid" API_KEY
    "units" "metric"
    "lang" "zh_cn"。

  定 完整URL = 网络.构建URL(URL, 参数)。
  
  尝试
    定 响应 = 网络.获取(完整URL)。
    定 数据 = JSON.解析(响应)。
    
    若 含数据 "main"
      则 典
        "城市" 数据["name"]
        "温度" 数据["main"]["temp"]
        "湿度" 数据["main"]["humidity"]
        "天气" 数据["weather"][0]["description"]
        "风速" 数据["wind"]["speed"]
        "更新时间" 日期.格式化(日期.当前时间(), "%Y-%m-%d %H:%M:%S")。
      否则 典"错误" "获取天气失败"。
  除
    典"错误" "网络请求失败"。

定 显示天气 = 函天气数据
  若 含天气数据 "错误"
    则 印("错误: " + 天气数据["错误"])
    则 (
      印("=" * 30)。
      印("城市: " + 天气数据["城市"])。
      印("温度: " + 转串(天气数据["温度"]) + "°C")。
      印("湿度: " + 转串(天气数据["湿度"]) + "%")。
      印("天气: " + 天气数据["天气"])。
      印("风速: " + 转串(天气数据["风速"]) + " m/s")。
      印("更新时间: " + 天气数据["更新时间"])。
      印("=" * 30)。
    )。

注 使用示例
定 天气 = 获取天气("Beijing")。
显示天气(天气)。
```
