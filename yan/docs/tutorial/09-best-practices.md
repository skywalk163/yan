```yan
注 命名规范示例
```

## 9.2 性能优化技巧

### 9.2.1 使用惰性计算

```yan
注 惰性计算示例

引 列表优化。

注 处理大型数据集时使用惰性列表
定 处理大型数据 = 函数据
  (数据
    | 列表优化.过滤(函x 大x 0)
    | 列表优化.映射(函x 乘x 2)
    | 列表优化.取(100))。

定 大数据 = 列表优化.范围(1, 1000000)。
定 结果 = 处理大型数据(大数据)。

印 结果.to_list()。
```

### 9.2.2 避免重复计算

```yan
注 缓存优化示例

定 缓存 = 典。

定 获取数据 = 函键
  若 含缓存 键
    则 (印 "使用缓存"; 缓存[键])
    则 (
      印 "计算中...";
      定 结果 = 乘键 2;  # 模拟耗时计算
      定 缓存[键] = 结果;
      结果
    )。

印 获取数据(5)。  # 计算中...
印 获取数据(5)。  # 使用缓存
印 获取数据(5)。  # 使用缓存
```

### 9.2.3 使用合适的数据结构

```yan
注 数据结构选择示例

注 快速查找使用字典
定 用户索引 = 典。

定 添加用户 = 函用户
  定 用户索引[用户["id"]] = 用户。

定 查找用户 = 函用户ID
  用户索引[用户ID]。

注 有序数据使用列表
定 日志列表 = 列。

定 添加日志 = 函日志
  定 日志列表 = 连日志列表 列日志。

定 获取最新日志 = 函数量
  取后日志列表 数量。
```

## 9.3 错误处理最佳实践

### 9.3.1 优雅的错误处理

```yan
注 错误处理示例

定 安全操作 = 函操作 错误消息
  尝试
    操作()
  除
    印("错误: " + 错误消息)。
    空。

定 读取文件 = 函路径
  安全操作(
    函 (打开文件路径; 读取内容),
    "无法读取文件: " + 路径
  )。
```

## 9.4 模块设计原则

### 9.4.1 单一职责原则

```yan
注 单一职责示例

注 用户管理模块
定 用户服务 = 函
  定 添加用户 = 函用户数据 ...。
  定 查询用户 = 函用户ID ...。
  定 更新用户 = 函用户ID 数据 ...。
  典"添加" 添加用户 "查询" 查询用户 "更新" 更新用户。

注 日志模块
定 日志服务 = 函
  定 记录 = 函消息 ...。
  定 警告 = 函消息 ...。
  定 错误 = 函消息 ...。
  典"记录" 记录 "警告" 警告 "错误" 错误。
```

### 9.4.2 模块间解耦

```yan
注 模块解耦示例

注 不依赖具体实现，依赖接口
定 处理器 = 函数据存储
  定 处理 = 函数据
    数据存储.保存(数据)。
    印 "处理完成"。
  处理。

注 可以替换不同的数据存储实现
定 文件存储 = 典"保存" 函数据 (写入文件数据; 真)。

定 文件处理器 = 处理器(文件存储)。
定 数据库处理器 = 处理器(数据库存储)。
```

## 9.5 测试最佳实践

### 9.5.1 单元测试

```yan
注 单元测试示例

套 "数学函数测试"

测 "加法测试":
  等(加1 2, 3)。
  等(加0 0, 0)。
  等(加-1 1, 0)。

测 "乘法测试":
  等(乘2 3, 6)。
  等(乘0 5, 0)。
  等(乘-2 -3, 6)。

测 "除法测试":
  等(除10 2, 5)。
  抛出(函 除10 0, 异常)。
```

### 9.5.2 测试覆盖

```yan
注 测试覆盖示例

套 "用户服务测试"

测 "添加用户":
  定 服务 = 用户服务()。
  定 ID = 服务.添加(典"姓名" "测试")。
  不为空ID。

测 "查询用户":
  定 服务 = 用户服务()。
  定 用户 = 服务.查询(1)。
  若 用户
    则 等(用户["姓名"], "测试")。

测 "更新用户":
  定 服务 = 用户服务()。
  服务.更新(1, 典"姓名" "新名字")。
  定 用户 = 服务.查询(1)。
  等(用户["姓名"], "新名字")。

测 "删除用户":
  定 服务 = 用户服务()。
  服务.删除(1)。
  定 用户 = 服务.查询(1)。
  为空用户。
```
