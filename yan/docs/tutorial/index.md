# 言语言入门教程

欢迎来到言语言（Yan Language）入门教程！

## 教程目录

1. **第1章：环境搭建** - 获取源代码，运行第一个程序
2. **第2章：基础语法** - 变量、数据类型、运算、条件语句、循环
3. **第3章：函数式编程** - 高阶函数、管道操作、皆/只/归
4. **第4章：模块系统** - 标准库、自定义模块、Python嵌入
5. **第5章：综合实战** - 10个实用项目示例

## 学习路线

```
第1章 → 第2章 → 第3章 → 第4章 → 第5章
  ↓         ↓         ↓         ↓
环境     基础     函数式    模块     实战
```

## 示例项目

所有示例项目位于 `examples/` 目录：

| 序号 | 项目 | 说明 |
|------|------|------|
| 1 | getting_started.yan | 入门示例：待办事项管理器 |
| 2 | optimizer_demo.yan | 优化器效果演示 |
| 3 | calculator.yan | 简单计算器 |
| 4 | todo.yan | 待办事项管理器 |
| 5 | fibonacci.yan | 斐波那契数列 |
| 6 | hanoi.yan | 汉诺塔问题 |
| 7 | wordcount.yan | 词频统计 |
| 8 | temperature.yan | 温度转换器 |
| 9 | json_process.yan | JSON数据处理 |
| 10 | guess_number.yan | 猜数字游戏 |
| 11 | countdown.yan | 倒计时器 |
| 12 | web_request.yan | 网络请求示例 |

## 运行示例

```bash
cd yan
python main.py examples/fibonacci.yan
```
