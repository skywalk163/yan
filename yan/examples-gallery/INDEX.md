## 📝 贡献指南

欢迎贡献新的示例项目！

### 贡献步骤

1. 选择合适的难度级别（basic/intermediate/advanced）
2. 遵循命名规范：`功能描述.yan`
3. 添加详细注释（使用 `注` 关键字）
4. 确保代码可以运行
5. 更新本INDEX文件

### 示例模板

```yan
注 项目名称 - 简短描述
注 作者：您的名字
注 难度：⭐⭐⭐

导入 标准库模块。

定 主函数 = 函 参数
  注 函数说明
  定 结果 = 处理 参数
  返回 结果

印 主函数 输入。
```
