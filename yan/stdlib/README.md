# 言语言标准库

言语言标准库提供丰富的内置函数和模块支持。

## 📦 模块列表

### 1. collections - 集合操作模块

高级集合和列表操作函数。

**核心函数：**
- `创建集合` - 创建集合
- `交集` - 集合交集
- `并集` - 集合并集
- `差集` - 集合差集
- `去重` - 列表去重
- `分组` - 列表分组
- `排序` - 列表排序
- `展平` - 展平嵌套列表

**示例：**
```yan
定nums=列1 2 3 2 1。
定unique=去重nums。
印unique。  -- 输出: [1, 2, 3]
```

### 2. io - 文件操作模块

文件和输入输出操作。

**核心函数：**
- `读文件` - 读取文件内容
- `写文件` - 写入文件
- `追加文件` - 追加写入文件
- `列目录` - 列出目录内容
- `存在文件` - 判断文件是否存在

**示例：**
```yan
定内容=读文件"data.txt"。
印内容。
```

### 3. math - 数学运算模块

数学运算和统计函数。

**核心函数：**
- `π` - 圆周率常量
- `e` - 自然常数
- `开方` - 平方根
- `对数` - 对数运算
- `正弦` - 正弦函数
- `阶乘` - 阶乘计算
- `随机整数` - 生成随机整数
- `随机小数` - 生成随机小数
- `随机种子` - 设置随机种子
- `正态随机` - 正态分布随机数

**示例：**
```yan
定x=开方16。
印x。  -- 输出: 4.0

定y=阶乘5。
印y。  -- 输出: 120
```

### 4. time - 时间处理模块

时间和日期处理函数。

**核心函数：**
- `当前时间` - 获取当前时间戳
- `格式化时间` - 格式化时间输出

- `日期间隔` - 计算日期差
- `是闰年` - 判断闰年
- `取年/取月/取日` - 获取日期组件

**示例：**
```yan
定now=当前时间戳。
印now。

```

### 5. string - 字符串处理模块

字符串操作和处理函数。

**核心函数：**
- `长度` - 获取字符串长度
- `拼接` - 字符串拼接
- `大写` - 转换为大写
- `小写` - 转换为小写
- `替换` - 字符串替换
- `分割` - 字符串分割
- `去空白` - 去除首尾空白

**示例：**

### 8. functional - 函数式编程模块

函数式编程工具和组合器。

**核心函数：**
- `组合` - 函数组合（先g后f）
- `管道` - 从左到右管道操作
- `映射` - 对列表每个元素应用函数
- `过滤` - 保留满足条件的元素
- `归约` - 用函数合并列表元素
- `扁平映射` - 先映射再展平
- `展平` - 展平嵌套列表
- `分组` - 按条件分组
- `分区` - 按条件分为两个列表
- `memoize` - 记忆化
- `柯里化` - 柯里化函数

**示例：**
```yan
引 functional。

定 nums = 列 1 2 3 4 5
定 squared = 映射 (函 x. 乘 x x) nums
印 squared  -- 输出: [1, 4, 9, 16, 25]

定 evens = 过滤 (函 x. 等 (模 x 2) 0) nums
印 evens  -- 输出: [2, 4]

定 sum = 归约 加 0 nums
印 sum  -- 输出: 15
```

### 17. logging - 日志模块

日志记录功能，支持多级别、日志文件和日志滚动。

**日志级别常量：**
- `DEBUG` - 调试级别 (1)
- `INFO` - 信息级别 (2)
- `WARNING` - 警告级别 (3)
- `ERROR` - 错误级别 (4)
- `CRITICAL` - 严重级别 (5)

**配置函数：**
- `设置日志级别` - 设置日志级别
- `设置日志文件` - 设置日志输出文件
- `设置日志格式` - 设置日志格式（支持 `%(时间)s`、`%(级别)s`、`%(消息)s` 占位符）
- `设置最大文件大小` - 设置日志文件最大大小（字节），默认 10MB
- `设置滚动时机` - 设置按时间滚动时机（"每天"/"每小时"/"每分钟"）
- `设置保留备份数` - 设置保留的备份文件数量，默认 5

**日志函数：**
- `debug` - 记录调试日志
- `info` - 记录信息日志
- `warning` - 记录警告日志
- `error` - 记录错误日志
- `critical` - 记录严重错误日志

**示例：**
```yan
引 logging。

设置日志级别 DEBUG。
设置日志文件 "app.log"。
设置日志格式 "%(时间)s [%(级别)s] %(消息)s"。
设置滚动时机 "每天"。
设置保留备份数 3。

debug "开始执行程序"。
info "用户登录成功"。
warning "内存使用率较高"。
error "连接数据库失败"。
critical "系统即将崩溃"。
```

### 18. cache - 缓存模块

提供内存缓存和文件缓存功能，支持 TTL 过期机制。

**初始化函数：**
- `初始化缓存` - 初始化缓存目录
- `设置TTL` - 设置默认 TTL（秒），默认 3600
- `设置文件缓存目录` - 设置文件缓存目录，默认 ".cache"
- `设置最大缓存大小` - 设置内存缓存最大条目数，默认 100

**内存缓存函数：**
- `内存缓存获取` - 从内存缓存获取值
- `内存缓存设置` - 设置内存缓存（键 值 过期时间）
- `内存缓存删除` - 删除内存缓存条目
- `内存缓存清空` - 清空所有内存缓存

**统一缓存函数：**
- `缓存获取` - 先查内存缓存，失败则查文件缓存
- `缓存设置` - 同时设置内存和文件缓存
- `缓存删除` - 删除内存和文件缓存
- `缓存清空` - 清空所有缓存
- `缓存大小` - 获取内存缓存条目数

**示例：**
```yan
引 cache。

初始化缓存。
设置TTL 7200。
设置最大缓存大小 50。

缓存设置 "user:1" 典 "name" "Alice" "age" 30 空。
定 user = 缓存获取 "user:1"。
印 user。

缓存删除 "user:1"。
印 缓存大小。
```

### 19. template - 模板引擎模块

提供模板渲染功能，支持变量、条件、循环、包含和模板继承。

**核心函数：**
- `渲染` - 渲染模板字符串
- `加载模板` - 从文件加载模板
- `渲染文件` - 加载并渲染模板文件
- `渲染包含` - 处理模板包含

**模板语法：**
- `{{变量名}}` - 变量替换
- `{% if 条件 %}...{% endif %}` - 条件判断
- `{% for 变量 in 列表 %}...{% endfor %}` - 循环遍历
- `{% include "文件名" %}` - 包含其他模板
- `{% extends "基模板" %}` - 模板继承
- `{% block 块名 %}...{% endblock %}` - 块定义（用于继承）

**示例：**
```yan
引 template。

定 模板 = "Hello, {{name}}! You have {{count}} messages."。
定 数据 = 典 "name" "Alice" "count" 5。
定 结果 = 渲染 模板 数据。
印 结果。  -- 输出: Hello, Alice! You have 5 messages.

定 条件模板 = "{% if is_vip %}VIP用户{% else %}普通用户{% endif %}"。
定 结果2 = 渲染 条件模板 典 "is_vip" 真。
印 结果2。  -- 输出: VIP用户

定 循环模板 = "{% for item in items %}{{item}},{% endfor %}"。
定 结果3 = 渲染 循环模板 典 "items" 列"苹果" "香蕉" "橙子"。
印 结果3。  -- 输出: 苹果,香蕉,橙子,
```

## 🔧 使用方法

### 导入单个模块
```yan
引 collections。
定nums=列1 2 3 4 5。
定unique=去重nums。
```

### 使用多个模块
```yan
引 collections。
引 math。
引 crypto。
引 database。
引 regex。
引 test。
```

### 导入模块中的特定函数
```yan
引 math 之 开方 阶乘。
印开方16。
印阶乘5。
```
