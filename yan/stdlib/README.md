# 言语言标准库

言语言标准库提供丰富的内置函数和模块支持。

## 📦 模块列表

### 1. collections - 集合操作模块

高级集合和列表操作函数。

**核心函数：**
- `创建集合` - 创建集合
- `交集` - 集合交集
- `并集` - 集合并集
- `差集` - 集合差集
- `去重` - 列表去重
- `分组` - 列表分组
- `排序` - 列表排序
- `展平` - 展平嵌套列表

**示例：**
```yan
定nums=列1 2 3 2 1。
定unique=去重nums。
印unique。  -- 输出: [1, 2, 3]
```

### 2. io - 文件操作模块

文件和输入输出操作。

**核心函数：**
- `读文件` - 读取文件内容
- `写文件` - 写入文件
- `追加文件` - 追加写入文件
- `列目录` - 列出目录内容
- `存在文件` - 判断文件是否存在

**示例：**
```yan
定内容=读文件"data.txt"。
印内容。
```

### 3. math - 数学运算模块

数学运算和统计函数。

**核心函数：**
- `π` - 圆周率常量
- `e` - 自然常数
- `开方` - 平方根
- `对数` - 对数运算
- `正弦` - 正弦函数
- `阶乘` - 阶乘计算
- `随机整数` - 生成随机整数

**示例：**
```yan
定x=开方16。
印x。  -- 输出: 4.0

定y=阶乘5。
印y。  -- 输出: 120
```

### 4. time - 时间处理模块

时间和日期处理函数。

**核心函数：**
- `当前时间` - 获取当前时间戳
- `格式化时间` - 格式化时间输出
- `睡眠` - 程序暂停
- `日期间隔` - 计算日期差
- `是闰年` - 判断闰年

**示例：**
```yan
定now=当前时间戳。
印now。

睡眠2。
印"等待2秒后继续"。
```

## 🔧 使用方法

### 导入单个模块
```yan
引 collections。
定nums=列1 2 3 4 5。
定unique=去重nums。
```

### 使用多个模块
```yan
引 collections。
引 math。
引 io。
```

### 导入模块中的特定函数
```yan
引 math 之 开方 阶乘。
印开方16。
印阶乘5。
```
