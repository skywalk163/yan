# 言语言标准库

言语言标准库提供丰富的内置函数和模块支持。

## 📦 模块列表

### 1. collections - 集合操作模块

高级集合和列表操作函数。

**核心函数：**
- `创建集合` - 创建集合
- `交集` - 集合交集
- `并集` - 集合并集
- `差集` - 集合差集
- `去重` - 列表去重
- `分组` - 列表分组
- `排序` - 列表排序
- `展平` - 展平嵌套列表

**示例：**
```yan
定nums=列1 2 3 2 1。
定unique=去重nums。
印unique。  -- 输出: [1, 2, 3]
```

### 2. io - 文件操作模块

文件和输入输出操作。

**核心函数：**
- `读文件` - 读取文件内容
- `写文件` - 写入文件
- `追加文件` - 追加写入文件
- `列目录` - 列出目录内容
- `存在文件` - 判断文件是否存在

**示例：**
```yan
定内容=读文件"data.txt"。
印内容。
```

### 3. math - 数学运算模块

数学运算和统计函数。

**核心函数：**
- `π` - 圆周率常量
- `e` - 自然常数
- `开方` - 平方根
- `对数` - 对数运算
- `正弦` - 正弦函数
- `阶乘` - 阶乘计算
- `随机整数` - 生成随机整数

**示例：**
```yan
定x=开方16。
印x。  -- 输出: 4.0

定y=阶乘5。
印y。  -- 输出: 120
```

### 4. time - 时间处理模块

时间和日期处理函数。

**核心函数：**
- `当前时间` - 获取当前时间戳
- `格式化时间` - 格式化时间输出
- `睡眠` - 程序暂停
- `日期间隔` - 计算日期差
- `是闰年` - 判断闰年

**示例：**
```yan
定now=当前时间戳。
印now。

睡眠2。
印"等待2秒后继续"。
```

### 5. string - 字符串处理模块

字符串操作和处理函数。

**核心函数：**
- `长度` - 获取字符串长度
- `拼接` - 字符串拼接
- `大写` - 转换为大写
- `小写` - 转换为小写
- `替换` - 字符串替换
- `分割` - 字符串分割
- `去空白` - 去除首尾空白
- `查找` - 查找子字符串

**示例：**
```yan
定s="Hello World"。
印大写s。  -- 输出: HELLO WORLD
印小写s。  -- 输出: hello world
印长度s。  -- 输出: 11
```

### 6. net - 网络请求模块

HTTP请求和网络通信功能。

**核心函数：**
- `GET` - 发送GET请求
- `POST` - 发送POST请求
- `PUT` - 发送PUT请求
- `DELETE` - 发送DELETE请求
- `状态码` - 获取响应状态码
- `内容` - 获取响应内容
- `JSON内容` - 获取响应JSON

**示例：**
```yan
定resp=GET"https://api.example.com/data"。
印状态码resp。
印内容resp。
```

### 7. json - JSON处理模块

JSON编码和解码功能。

**核心函数：**
- `解析` - 解析JSON字符串
- `生成` - 生成JSON字符串
- `读文件` - 读取JSON文件
- `写文件` - 写入JSON文件
- `有效?` - 检查是否为有效JSON
- `合并` - 合并两个JSON对象
- `过滤` - 过滤JSON数据

**示例：**
```yan
定obj=解析'{"name":"Alice","age":30}'。
印obj["name"]。

定json_str=生成obj。
印json_str。
```

## 🔧 使用方法

### 导入单个模块
```yan
引 collections。
定nums=列1 2 3 4 5。
定unique=去重nums。
```

### 使用多个模块
```yan
引 collections。
引 math。
引 io。
引 string。
引 net。
引 json。
```

### 导入模块中的特定函数
```yan
引 math 之 开方 阶乘。
印开方16。
印阶乘5。
```

### 使用网络请求
```yan
引 net。

定 resp = GET "https://api.github.com/users"。
印 状态码 resp。
印 JSON内容 resp。
```

### 使用JSON处理
```yan
引 json。

定 data = 解析 '{"name":"Alice","score":95}'。
印 data["name"]。

定 json_str = 生成 data。
```
